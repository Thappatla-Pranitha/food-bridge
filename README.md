# Food Bridge 🍲

A food donation platform designed to connect food donors with people in need.

## 🎯 Objective
Reduce food waste and make surplus food easier to share with communities.

## 🛠️ Technology Stack
- Java
- Spring Boot
- REST APIs
- MySQL (planned)
- Git and GitHub

## ✨ Planned Features
- Register food donations
- View available food listings
- Retrieve a food listing by ID
- Connect donors and receivers
- Add database persistence and validation

## 📌 Project Status
**In development.** The initial project structure and API are being built.
